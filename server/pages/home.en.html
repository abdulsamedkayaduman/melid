Everything you do daily, in one place

No need to open separate programs for the terminal, file transfers and server management.

Tabbed terminal

Tabs, split panes, two groups side by side. Send a command to many servers at once; it reconnects by itself if the connection drops.

SFTP file manager

Local and remote panels side by side. Drag and drop, copy and paste, resuming interrupted transfers, folder sync and editing remote files in your own editor.

Server to server

Files are copied directly between two servers without passing through your computer. Jump hosts, -L / -R / -D tunnels and ssh-agent support.

Bulk actions

Check all your servers in one click: which are reachable, which need a password. Run commands on many servers and see a CPU / RAM / disk summary.

Sync across devices

Sessions, saved passwords, settings and snippets sync between your computer and your phone. SSH keys too, if you want.

Easy migration

Import your Xshell (with passwords and tunnels), MobaXterm and WindTerm sessions. Your computer's own shell also opens in a tab. Take encrypted backups and restore them.

Your data is yours

Sync is end-to-end encrypted: the encryption key is derived from your account password on your device and is never sent to the server.

What the server sees

  • Your username and email address. To contact you about your account if needed.
  • The size of your encrypted vault and the last sync time.
  • Which devices you connect from (e.g. "Melid 1.12.1 Windows").
  • Usage counts: daily connection and transfer counts, number of saved servers. Numbers only, never content; can be turned off in the app. Details

What the server can't see

  • Your account password. Only a verification key derived from it reaches the server.
  • Server addresses, usernames, passwords and keys. All inside the vault, encrypted.
  • What you type in the terminal and the files you transfer. SSH connections go directly from your device to your server.

If you forget your account password, nobody can open your vault, so create a recovery key in the account window and keep it safe. You can delete your account from the app at any time; your encrypted vault is deleted from the server too. Melid works without an account; sync is optional.

First-time setup on macOS

The app isn't signed by Apple, so the first installation needs these commands in Terminal:

tar xzf Melid-*-mac-arm64.tar.gz
mv Melid.app /Applications/
xattr -cr /Applications/Melid.app
codesign --force --deep --sign - /Applications/Melid.app

Then open it from Launchpad. Updates are announced in the app; install new versions with the same steps.

Installing on Linux

The AppImage runs on any distribution and needs no installation:

chmod +x Melid-*.AppImage
./Melid-*.AppImage

If Ubuntu 22.04 or newer reports a "FUSE" error: sudo apt install libfuse2 (libfuse2t64 on Ubuntu 24.04).

On Arch, CachyOS, Manjaro the pacman package adds "Melid" to the app menu and the melid command:

sudo pacman -U melid-*.pacman

Saved passwords are encrypted in the system keyring (GNOME Keyring / KWallet); without a keyring, set a master password in Settings. New versions are announced in the app and install in one click (the pacman package asks for the administrator password).

How do I move from Xshell?
  1. Export your sessions in Xshell: you get an .xts file.
  2. In Melid, choose this file with Import → Xshell in the toolbar. Folders, addresses, usernames, passwords and tunnels come along.
  3. Passwords: decrypted automatically on the same Windows computer with the same user. If you set a master password in Xshell, Melid asks for it. On another computer (Linux, macOS or another Windows), type whoami /user in a command prompt on the Windows computer where Xshell is installed, and enter the username and the SID starting with S-1-5-21-… into the window Melid shows.
  4. A result like "91 of 133 passwords decrypted" is not an error: the rest were saved on another computer or with an old master password. Try another master password, or choose Continue without the remaining passwords; the password is asked on first connection.

Private keys in Xshell's own key store are not imported: export them from Xshell and put them in ~/.ssh. Xshell import is in the desktop app.

How do I create a sync account?
  1. Click the cloud (Account) button in the app and choose Create account.
  2. melid.abdulsamed.net is filled in as the server. Enter a username, email and an account password of at least 10 characters.
  3. On your other devices, choose Log in with the same details.
Can I run my own sync server?

Yes. The server is a single-file Node app with no dependencies and sets up in minutes with Docker. Just replace the server address in the app with yours; the app can even find a server on your local network.
